# Getting Started

Welcome to the Claude Agent App! This is an AI-powered assistant backed by Claude with access to configured MCP tools.

## What I can help with

- Answering questions and having conversations
- Using connected MCP tools (e.g., Slack, databases) on your behalf
- Helping with tasks using your personal Databricks workspace permissions

## How it works

Each conversation maintains its own agent context, so I remember what we discussed within a session. Your personal OAuth token is used for all tool calls, so actions are performed as you — not a shared service account.

## Getting started

Just start chatting! Create a new conversation and type your first message. If you want to use specific tools, ask me to help with that task and I'll use the available MCP connections automatically.
